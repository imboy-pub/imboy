## 🧪 测试场景

### 场景 1: 本地备份导出/导入（方法 C）

#### 测试步骤

**1.1 导出备份**
- [ ] 登录账号 A
- [ ] 进入"端到端加密密钥管理"
- [ ] 点击"本地备份" → "导出备份"
- [ ] 设置备份密码（测试密码：`Test@123456`）
- [ ] 验证备份文件生成成功
- [ ] 保存备份文件到文档

**1.2 导入备份**
- [ ] 清除本地密钥（模拟新设备或密钥丢失）
  - 进入"端到端加密密钥管理"
  - 点击"生成新密钥"
  - 确认警告
- [ ] 返回密钥管理页面
- [ ] 点击"本地备份" → "导入备份"
- [ ] 选择之前导出的备份文件
- [ ] 输入备份密码：`Test@123456`
- [ ] 验证密钥恢复成功
- [ ] 检查密钥信息显示正确

**1.3 密码错误测试**
- [ ] 尝试导入备份时输入错误密码
- [ ] 验证显示"密码错误"提示

#### 预期结果
- 导出成功生成 `.imboy_backup` 文件
- 导入成功恢复密钥
- 错误密码显示相应错误提示

---

### 场景 2: 设备间传输（方法 A）

#### 测试步骤

**2.1 创建传输会话**
- [ ] 在设备 A 上登录账号 A
- [ ] 进入"端到端加密密钥管理"
- [ ] 点击"设备间传输" → "发送密钥"
- [ ] 输入设备 B 的用户 ID（账号 B）
- [ ] 点击"创建传输会话"
- [ ] 验证显示二维码

**2.2 接收传输**
- [ ] 在设备 B 上登录账号 A
- [ ] 进入"端到端加密密钥管理"
- [ ] 点击"设备间传输" → "接收密钥"
- [ ] 扫描设备 A 显示的二维码
- [ ] 验证显示传输详情（会话 ID、过期时间）
- [ ] 点击"接受传输"

**2.3 完成传输**
- [ ] 设备 A 上确认传输
- [ ] 验证两台设备都显示"传输成功"

**2.4 会话过期测试**
- [ ] 等待 5 分钟后尝试接收
- [ ] 验证显示"会话已过期"错误

#### 预期结果
- 二维码正确生成和扫描
- 传输成功，密钥恢复
- 过期会话正确拒绝

### 场景 3: 社交恢复 - 创建分片（方法 B）

#### 测试步骤

**3.1 准备好友关系**
- [ ] 确保账号 A 与 B、C、D 是好友
- [ ] 确保所有账号都启用了 E2EE

**3.2 创建恢复分片**
- [ ] 在账号 A 上登录
- [ ] 进入"端到端加密密钥管理"
- [ ] 点击"社交恢复" → "创建恢复分片"
- [ ] 设置分片参数：
  - 总分片数：3
  - 恢复阈值：2
- [ ] 点击"添加代理"
- [ ] 验证打开好友选择器
- [ ] 选择账号 B、C、D（各选择一个）
- [ ] 确认选择
- [ ] 点击"创建分片"
- [ ] 验证显示"分片创建成功"

**3.3 查看已创建分片**
- [ ] 返回社交恢复主页
- [ ] 点击"管理分片"
- [ ] 验证显示 3 个分片信息
- [ ] 切换到"代理分片"标签
- [ ] 验证显示代理的分片（账号 B、C、D）

#### 预期结果
- 分片创建成功
- 代理信息正确显示
- 标签页切换正常

### 场景 4: 社交恢复 - 恢复密钥（方法 B）

#### 测试步骤

**4.1 清除密钥（模拟新设备）**
- [ ] 在账号 A 上清除本地密钥
  - 进入"端到端加密密钥管理"
  - 点击"生成新密钥"创建新密钥

**4.2 恢复密钥**
- [ ] 返回"社交恢复"主页
- [ ] 点击"恢复密钥"
- [ ] 验证显示可用分片列表
- [ ] 选择至少 2 个分片
- [ ] 验证顶部显示"可以恢复密钥"
- [ ] 点击"恢复密钥"
- [ ] 验证显示"恢复成功"

**4.3 分片不足测试**
- [ ] 尝试只选择 1 个分片
- [ ] 验证显示"需要更多分片"提示

**4.4 查看分片状态**
- [ ] 进入"管理分片"
- [ ] 验证之前使用的分片状态变为"已使用"

#### 预期结果
- 密钥恢复成功
- 分片状态正确更新
- 验证逻辑正确
