# Imboy 客户验收清单（一期标准版）

> Last Updated: 2026-03-08  
> Status: 长期交付文档  
> Related docs: `doc/guides/deployment.md`, `doc/guides/three-end-phase1-function-matrix.md`, `doc/guides/product-edition-comparison.md`

## 1. 文档目的

本文档用于为 `Imboy` 的标准交付、私有化部署和联调验收提供统一清单。

目标是把“是否可交付”从口头判断变成可执行、可记录、可追踪的验收流程。

本文档默认适用于：

1. 一期主包；
2. 已明确购买的高配能力；
3. 未明确购买的二期模块默认关闭场景。

## 2. 适用范围

默认验收对象包括：

1. 后端服务 `imboy`；
2. 移动端客户端 `imboyapp`；
3. 管理后台 `imboy-admin-frontend`；
4. 部署、联调、治理和基础运维能力。

若客户购买了模块化能力，应在本文基础上追加模块专项验收。

## 3. 验收结论定义

### 3.1 结论等级

- **通过**：所有阻断项通过，允许上线或交付。
- **有条件通过**：存在非阻断问题，但有明确绕行或计划修复方案。
- **不通过**：存在阻断项，不能交付或不能上线。

### 3.2 问题等级

- **P0 阻断**：影响部署、登录、收发消息、基础治理、数据安全。
- **P1 重要**：不阻断主链路，但明显影响使用、验收或运维。
- **P2 一般**：体验、文案、样式或可延期问题。

## 4. 验收前置条件

在开始验收前，必须确认以下事项已准备：

1. 部署环境已就绪；
2. 数据库与必要依赖已初始化；
3. 管理后台与 App 的目标地址已配置；
4. 测试账号、测试群、测试数据已准备；
5. 验收模块清单已冻结；
6. 未采购模块已明确为默认关闭。

## 6. 高配能力专项验收

### 6.1 `E2EE`

仅在购买或启用时验收：

1. 密钥状态可查询；
2. 加密消息可收发；
3. 多设备链路行为符合预期；
4. 恢复或转移链路可执行；
5. 未启用时不影响主包消息链路。

### 6.2 `Channel`

仅在购买或启用时验收：

1. 频道列表、详情、订阅、取消订阅可用；
2. 频道消息发布、查看、未读同步可用；
3. 后台频道治理页可用；
4. 未启用时 App 与后台不暴露无效入口。

## 7. 二期模块关闭态验收

若客户未购买二期模块，必须额外验证关闭态：

1. 客户端不展示相关入口；
2. 后台菜单不展示相关页面；
3. 路由不可直接访问或访问时有明确提示；
4. 后端接口返回一致的“未启用”语义；
5. 关闭态不影响一期主包门禁。

默认关闭模块包括：

1. `location`
2. `moment`
3. `channel_discover / channel_order`
4. `group_vote / group_schedule / group_task`

### 7.1 功能开关三端回归清单

建议每次售卖版本冻结后，至少按下表完成一次开/关回归：

| 模块 | 后端检查 | App 检查 | 后台检查 | 结果 | 备注 |
|---|---|---|---|---|---|
| `channel=false` | `/v1/app/features` 返回 `channel=false`，频道受保护接口不可用 | 底部频道 `Tab` 不展示，旧链接进入频道页被路由守卫拦回 | `Sidebar` 不展示频道菜单，频道路由不可直达 |  |  |
| `channel_invitation=false` | 相关接口返回关闭态 | 频道列表 / 频道详情不展示邀请入口 | 频道详情不展示“邀请”，邀请页不可直达 |  |  |
| `channel_order=false` | 相关接口返回关闭态 | 频道详情不展示订单入口 | 频道详情不展示“订单”，订单页不可直达 |  |  |
| `moment=false` | 动态相关接口返回关闭态 | 频道页不展示朋友圈入口，旧动态链接被拦回 | 菜单不展示朋友圈治理，`/moments` 与 `/reports` 不可直达 |  |  |
| `location=false` | `people_nearby` 相关接口返回关闭态 | 联系人页不展示“附近的人”，旧链接被拦回 | 不适用 |  |  |
| `group_vote=false` | 群投票接口返回关闭态 | 旧投票路由不可直达 | 群详情不展示“投票管理”，投票治理页不可直达 |  |  |
| `group_schedule=false` | 群日程接口返回关闭态 | 旧日程路由不可直达 | 群详情不展示“日程管理”，日程治理页不可直达 |  |  |
| `group_task=false` | 群任务接口返回关闭态 | 旧任务路由不可直达 | 群详情不展示“任务管理”，任务治理页不可直达 |  |  |

### 7.2 推荐执行顺序

1. 先确认 `sys.config` 与客户购买清单一致；
2. 再用 `GET /v1/app/features` 与 `GET /adm/admin/config/features` 核对生效值；
3. 然后执行 App 入口显隐、后台菜单显隐与直达路由回归；
4. 最后做一轮接口级反向验证，确认未售卖模块不会只“前端隐藏、后端放开”。

### 7.3 建议留证

建议每个关闭模块至少保留以下证据：

1. 一张 App 入口显隐截图；
2. 一张后台菜单或详情页按钮显隐截图；
3. 一条接口返回关闭态的命令或抓包结果；
4. 一条旧链接直达被守卫拦回的录屏或截图。
