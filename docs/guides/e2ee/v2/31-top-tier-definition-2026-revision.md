# ADR 31 — Top-tier Definition 2026 Revision（顶级定义 2026 修订：按安全属性验收，不按协议名验收）

> **状态**：**Accepted**（2026-08-02 leeyi solo 一人决策——单人开发，一人兼五方；签字记录见 §5。v2/20 号文 G5 的 MLS 前提自即日起被本文取代）
> **关联**：v2/20（G5 验收定义被修订）、v2/19（MLS ADR，维持 Proposed）、`../standard/top-tier-standard-2026.md`（本决策的操作化）、`../standard/research/`（决策依据快照）

## 1. 背景

v2/20《行业顶级 E2EE 实施与验收计划》G5 规定：只有"MLS 群范围也达到门禁，才可发布 GA-Top-Tier"——即**顶级=必须实现 MLS**。

2026-08-01 行业调研（`../standard/research/`）与用户决策带来三个新事实：

1. **行业验收实践已转向"安全属性"**：WhatsApp 无 PQ、无 MLS 仍被市场与审计界视为顶级（NCC 两次审计+AKD 公开复算）；Signal 走 Signal Protocol+PQ 路线而非 MLS；MLS 生产用户（Wire/Discord/RCS）服务的是"大群/跨厂商互通"场景，与 IMBoy 自托管小群场景不同。**没有任何一家以"协议名=MLS"作为顶级定义**。
2. **IMBoy 的现有资产是 Olm/Megolm 系**：vodozemac（Least Authority 2022 已审计）、room-key-over-Olm（ADR 13 Frozen）、PFv3、trust 事件、KT Merkle 库——迁 MLS 将使这些资产大部分作废，且 MLS 生态库 pre-1.0、审计覆盖不全（mls-rs 自认未审计）。
3. **用户在 2026-08-01 明确四项拍板**：① Olm/Megolm 加固到底，不迁 MLS；② 审计形态=审计就绪包（不采购第三方审计）；③ PQ 不纳入，列路线图；④ 在途收口纳入第一阶段。

## 2. 决策

1. **GA-Top-Tier 重定义**：由"实现 MLS 群聊并过门禁"改为"满足 `standard/top-tier-standard-2026.md` 全部 MUST 条目（按安全属性定义）"。协议选型（Olm/Megolm vs MLS）不再是验收条件，安全属性（FS/PCS/成员隔离/可验证性/可审计性）才是。
2. **MLS 移出 GA 前提**：ADR 19 维持 Proposed 不签字；MLS 转为路线图项 TT-R2，触发升级条件=生态库 1.0+审计全覆盖，或大群（>1000）/跨厂商互通成为产品硬需求。
3. **PQ 列路线图项 TT-R1**：触发升级条件=Signal/Apple 之外 ≥1 家主流 IM 生产部署，或买家合同要求。协议扩展位（capability 协商/套件注册表）保留。
4. **审计形态=审计就绪包**：TT-D5 从 MUST（第三方审计）降为 SHOULD（就绪包+SOW+自审计报告）；采购真实审计另立商业决策。
5. **标准驱动维护模型**：验收标准版本化独立于实施计划；行业标准演进时改 Research→升 Standard 版本→刷 Gap Matrix，**不重写实施计划**（`../standard/README.md`）。

## 3. 备选方案与否决理由

| 方案 | 否决理由 |
|---|---|
| A. 直接迁 MLS（v2/20 S4 原案） | 现有 vodozemac/ADR13/PFv3/KT 资产作废；生态库 pre-1.0；大群/互通非 IMBoy 当前场景；投入 L 级且延误所有在途收口 |
| B. 双轨（Megolm 加固+MLS 预研 POC） | 用户已明确不迁；POC 仍会分散 P0-P2 收口资源；TT-R2 触发条件出现时再评估不迟 |
| C. 维持 G5 原定义（MLS 必须）但无限推迟 GA | 验收标准永远不可达=验收体系名存实亡，比修订定义更有害 |
| D. PQ 混合握手立即纳入 | 用户拍板不纳入；WhatsApp 先例证明无 PQ 不妨碍顶级认定；成本=预密钥体积 50 倍+双端协议改动 |

## 4. 后果

**正面**：
- GA-Top-Tier 变为可达目标（全部 MUST 条目均有关闭任务，见 gap-matrix.md）。
- 验收语言与审计界通行做法对齐（范围锚定+安全属性+可复算证据）。
- 标准升版机制使 PQ/MLS 未来转默认要求时**只改标准与差距矩阵**。

**代价/约束**：
- v2/20 §10 G5 表格与 §4 阶段表（S4=MLS）需随签字修订（任务 P6-1）。
- v2/22 号文件的"当前发布声明"段（"群聊 MLS 完成才可宣称 GA-Top-Tier"）需同步修订。
- 对外口径红线：MLS/PQ 一律"路线图"措辞；不可暗示已具备（evidence-matrix.md §4）。
- Megolm 的先天短板（成员变更 O(n)、PCS 依赖轮换纪律）必须通过 TT-A3/A4 的实测与台账诚实登记，不得借本决策回避。
