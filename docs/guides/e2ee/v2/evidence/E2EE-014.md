## 关键前提（现状核实）

`rg` 全仓确认 **imboyapp 无任何 trust-event 客户端**（无签名/无调用 `/e2ee/trust/record`，仅 i18n 文案）。故本次为**非破坏性后端硬化**：无现存客户端会因 canonical 扩字段而验签失败。客户端 trust 验证/签名 UI 为独立后续（部分属 ADR 16 §5 cross-signing，仍 Proposed）。

## 已确认漏洞（修复前）

- trust event 无 freshness：`ts` 在签名内但服务端不校验时间窗 → 捕获的合法 `verified`/`revoke` 事件可**永久重放**。
- 无唯一性/幂等：同一事件重放 → 多条审计行 + 多次广播。
- 无 target 身份版本单调、无 actor 撤销校验 → 回退/撤销后仍可写。

## 修复（da1cb358）

- **canonical 扩至 11 字段**（§3.3.1，字典序 `key=value\n`）：新增 actor_uid / actor_device_generation / event_id / issued_at / expires_at / target_identity_version；`ts→issued_at`。`canonical_payload/1` + `record_trust_event/2` 改 map 版。
- **freshness**：`issued_at∈[now-300000, now+120000]`、`expires_at∈(issued_at, issued_at+300000]`、`now≤expires_at`；失败统一 `stale_event`（单一错误，不泄时间 oracle）。
- **幂等**：`trust_audit_repo:insert_event` `ON CONFLICT (event_id) WHERE event_id IS NOT NULL DO NOTHING RETURNING id`；`{ok,inserted}` 才广播，`{ok,duplicate}` 返回 ok 不重播、不重复审计。
- **单调**：`max_target_identity_version/2`，本次 `target_identity_version < max` → `identity_version_rollback`。
- **撤销/旧设备**：`actor_device_state/2`（读 user_device）要求 `status=1` 且 `device_generation` == 签名声明值；否则 `actor_device_revoked`。
- 校验顺序：method/非空/整数 → 状态转换白名单 → freshness → actor 身份+active+代数 → 验签 → 单调 → 幂等写+广播。转换/freshness 在 DB/验签前（省资源、不给 oracle）。

## Verification

- `make app` 干净编译。
- `make eunit t=e2ee_trust_logic` → **All 20 tests passed**：
  - 有效写+广播（非 revoked 仅发 actor；revoked 同发 target）。
  - 验签失败拒写拒播；actor 设备未注册拒。
  - **freshness -1/0/+1ms 边界**：过去边界 `now-300000` 且 expires 达 now 接受、`now-300001` 拒；未来 `now+120001` 拒；已过期（now>expires）拒。
  - **event_id 幂等**：`{ok,duplicate}` → ok 且 `msg_s2c_ds:send` 0 次。
  - **单调**：历史 max=5、本次=1 → `identity_version_rollback`，insert 0 次。
  - **撤销 actor**（status=0）/ **代数失配**（存 2 签 1）→ `actor_device_revoked`。
  - 非法转换（revoked→verified，验签前拒）、同态、非法 method、空 event_id/设备字段、非整数 issued_at 拒。
  - canonical 确定性 + 字段雪崩。
- **migration 47 真 PG（imboy_v1 回滚事务）**：up/repeat-up 幂等/dup event_id 拒/多 NULL 允许/down 清 7 列+索引（见 `3534e503`）。
