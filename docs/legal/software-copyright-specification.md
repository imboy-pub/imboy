## 二、软件概述

### 2.1 软件简介

IMBoy 即时通讯系统是一款基于 Erlang/OTP 高并发服务端和 Flutter 跨平台客户端的即时通讯解决方案。系统由三大核心子系统构成：即时通讯后端服务、跨平台移动客户端和管理后台。

后端服务基于 Erlang/OTP 28+ 和 Cowboy 2.10 构建，采用 DDD（领域驱动设计）四层架构（Handler → Logic → DS → Repo），配合 PostgreSQL 18+ 关系型数据库，单机支持百万级 TCP 并发连接。

移动客户端基于 Flutter 3.41.x 开发，采用 Riverpod 状态管理和 go_router 声明式路由，通过 WebSocket 保持实时消息链路，通过 WebRTC 实现音视频通话，本地使用 SQLite 进行数据持久化。

管理后台基于 React + TypeScript + Vite 构建，提供完整的用户管理、群组管理、消息审计、系统配置等运营管理功能。

## 三、功能说明

### 3.1 用户管理模块

#### 3.1.1 用户注册

系统支持手机号注册方式。用户输入手机号码、设置密码后完成注册。注册时系统自动生成唯一用户标识，并将用户信息加密存储至数据库。

操作流程：
1. 用户打开应用，进入注册页面
2. 输入手机号码
3. 设置登录密码（需满足安全强度要求）
4. 点击"注册"按钮
5. 系统验证信息后完成注册，自动跳转至主页面

#### 3.1.2 用户登录

系统支持账号密码登录。登录成功后系统生成 JWT 令牌用于后续接口鉴权，同时建立 WebSocket 长连接以接收实时消息。

操作流程：
1. 用户输入账号和密码
2. 点击"登录"按钮
3. 系统验证凭证，生成认证令牌
4. 自动建立 WebSocket 连接
5. 加载离线消息和会话列表

#### 3.1.3 个人信息管理

用户可以修改个人资料，包括昵称、头像、签名等信息。系统支持头像上传和裁剪功能。

### 3.2 消息通讯模块

#### 3.2.1 单聊（C2C）

系统支持一对一即时消息通讯，支持以下消息类型：
- **文本消息**：支持表情符号和富文本
- **图片消息**：支持拍照和相册选择，自动压缩上传
- **语音消息**：支持录音发送，显示时长
- **视频消息**：支持录制和选择视频文件
- **文件消息**：支持发送各类文件
- **位置消息**：支持发送当前位置信息
- **名片消息**：支持分享联系人名片

消息投递机制（QoS）：
1. 判断接收方是否在线
2. 在线则通过 WebSocket 立即投递
3. 未确认则按梯度重试：2秒 → 5秒 → 7秒 → 11秒
4. 4次投递失败后存储为离线消息
5. 接收方上线后自动推送离线消息

#### 3.2.2 群聊（C2G）

系统支持多人群组聊天，群组功能包括：
- 创建群组（支持面对面建群）
- 邀请成员加入群组
- 群组消息广播
- 群主和管理员权限管理
- 群公告发布
- 群成员管理（踢出、禁言等）

#### 3.2.3 系统消息（S2C）

系统可向用户推送系统通知，包括：
- 好友申请通知
- 群组邀请通知
- 系统公告
- 版本更新提醒

#### 3.2.4 端到端加密（E2EE）

系统实现了完整的端到端加密通讯机制：
- 加密套件：RSA-OAEP-256 + AES-256-GCM
- 设备公钥管理与同步
- 密钥恢复方案：设备间传输、社交恢复、本地备份
- 服务端不解密消息密文，仅做路由和存储

### 3.3 音视频通话模块

#### 3.3.1 语音通话

基于 WebRTC 实现的点对点语音通话功能：
- 一对一语音通话
- 通话状态管理（呼叫、接听、挂断、拒接）

#### 3.3.2 视频通话

基于 WebRTC 实现的点对点视频通话功能：
- 一对一视频通话
- 前后摄像头切换
- 视频画面缩放
- 通话中静音/关闭摄像头

### 3.4 联系人管理模块

#### 3.4.1 好友管理

- 搜索添加好友（支持手机号、账号搜索）
- 好友申请与审批

### 3.5 会话管理模块

### 3.6 频道模块

## 四、系统安全

### 4.1 认证安全

- JWT（JSON Web Token）令牌认证
- Token 自动刷新机制
- 多设备登录管理

### 4.2 数据安全

- RSA 非对称加密用于密钥交换
- AES-256-GCM 对称加密用于消息加密
- 端到端加密确保服务端无法解密消息内容
- HashID 混淆用户标识，防止信息泄露
- 所有 SQL 操作使用参数化查询，防止 SQL 注入

### 4.3 通讯安全

- WebSocket 支持 WSS（TLS/SSL）加密传输
- HTTPS 安全通讯
- 资源 URL 授权签名机制，防止未授权访问

## 六、使用说明

### 6.1 安装与启动

#### 6.1.1 客户端安装

用户可通过以下方式安装客户端：
- iOS：通过 App Store 下载安装
- Android：通过应用市场或 APK 安装包安装

#### 6.1.2 首次使用

1. 打开应用后进入登录/注册页面
2. 新用户选择"注册"，填写手机号和密码完成注册
3. 已有账号用户输入账号密码登录
4. 登录成功后进入会话列表主页面

### 6.2 核心功能操作

#### 6.2.1 发送消息

1. 在会话列表中选择联系人或点击右上角新建聊天
2. 进入聊天界面
3. 在底部输入框输入文本消息，点击发送按钮
4. 点击"+"按钮可选择发送图片、视频、文件、位置等多媒体消息
5. 长按消息可进行复制、转发、撤回、收藏等操作

#### 6.2.2 创建群组

1. 进入联系人页面
2. 点击"创建群组"或"面对面建群"
3. 选择群成员
4. 设置群名称
5. 点击确认创建群组

#### 6.2.3 音视频通话

1. 进入与联系人的聊天界面
2. 点击右上角的电话或视频图标
3. 等待对方接听
4. 通话中可进行静音、切换摄像头、关闭视频等操作
5. 点击挂断按钮结束通话

#### 6.2.4 发布朋友圈

1. 进入朋友圈页面
2. 点击右上角的发布按钮
3. 输入文字内容，选择图片或视频
4. 设置可见范围
5. 点击发布

### 6.3 管理后台操作

#### 6.3.1 登录管理后台

1. 使用浏览器打开管理后台地址
2. 输入管理员账号和密码
3. 点击登录进入管理界面

#### 6.3.2 用户管理

1. 在左侧菜单中选择"用户管理"
2. 可查看用户列表，支持按关键字搜索和条件筛选
3. 点击用户可查看详细信息
4. 可对用户进行启用/禁用操作

#### 6.3.3 系统配置

1. 在左侧菜单中选择"系统设置"
2. 可配置应用版本信息
3. 管理功能开关
4. 发布系统公告

## 八、软件特点

1. **高并发架构**：基于 Erlang/OTP 的 Actor 模型，天然支持高并发和分布式
2. **跨平台客户端**：基于 Flutter 一套代码覆盖 iOS、Android、macOS 多平台
3. **端到端加密**：完整的 E2EE 实现，保障通讯安全
4. **消息可靠投递**：多级重试和离线消息机制确保消息不丢失
5. **模块化架构**：采用 DDD 领域驱动设计，各模块高内聚低耦合
6. **多语言支持**：支持10种语言，方便国际化推广
7. **完善的管理系统**：提供全面的运营管理后台
8. **开放许可证**：采用木兰宽松许可证 v2，支持自由使用和修改
