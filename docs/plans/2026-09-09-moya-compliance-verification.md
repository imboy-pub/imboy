## 4. 草拟材料（全部为草稿，不对外，需专业人士复核）

### 4.1 监护人同意书要点（草稿清单）

1. **谁在征集同意**：机构全称（个人信息处理者）＋技术支持方名称（受托处理方）；不得只写"墨芽"品牌名。
2. **同意对象**：针对"不满十四周岁学员的练字视频、作品照片及相关教学信息"的收集与处理（敏感个人信息 → 需**单独同意**，不得混在 general 服务条款里勾选）。
3. **处理目的与方式**：作业提交、老师回评、AI 辅助生成点评草稿（明确说明 AI 仅辅助老师、不直接对孩子输出结论）、成长记录。
4. **视频用途明示**：仅用于（a）任课老师回评（b）AI 生成供老师核对的结构化草稿（c）按监护人要求的成长记录回看；**不用于模型训练**、不公开、不分享给班级以外人员。
5. **接收者范围**：任课老师、班级管理者（按授权）、机构管理员（按策略）、技术受托方（仅按指令处理）；列明不含第三方广告/营销。
6. **保存期限**：明示具体时长（如学期结束后 N 天内删除或按监护人要求提前删除），不得写"永久保存"。
7. **撤回方式**：监护人可随时在小程序内撤回同意、要求删除；撤回路径不超过 N 步操作；撤回不影响撤回前基于同意进行的处理的合法性。
8. **监护人权利**：查阅、复制、更正、删除、解绑账号（依据未成年人网络保护条例第 34 条）。
9. **显著性与可理解性**：关键信息前置、平实语言、不使用默认勾选；留存同意时间戳与版本号（审计）。
10. **不满 14 周岁的判断**：以学员档案出生年/监护人申报为准；存疑按儿童标准处理（宁可从严）。

### 4.3 儿童信息删除 / 导出 / 更正 / 解绑路径（产品级草稿）

## 6. 结论

1. **核验完成度**：主体/类目/备案/认证/儿童隐私/平台隐私配置/支付门槛均已锚定官方或权威来源（LEGAL-01 满足）；6 项细节列入待人工核验清单。
2. **三道门禁**：开发版（合成数据）现在即可 GO；真实试点以"主体可承载视频类目 + 协议 + 监护人同意 + 四路径演练 + ACL 验证 + 备案"为 GO 条件；正式发布以"非个人主体 + 认证 + 类目过审 + 备案下发"为 GO 条件（LEGAL-02 满足）。
3. **个人主体结论**：官方类目文档明确个人主体教育类目不支持视频服务，个人主体路径对墨芽核心功能构成结构性阻断；机构主体路径资质明确（4 选 1）。该结论是核验事实，最终主体选择权在用户（LEGAL-03 满足）。
