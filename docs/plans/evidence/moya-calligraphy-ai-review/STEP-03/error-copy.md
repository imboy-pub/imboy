# 墨芽小程序错误文案表（Coordinator 代 Agent A 产出）

> 依据：STEP-04/error-codes.md（Step 4 冻结）。覆盖复用通用码 + 教学域 5400-5519 全号段。
> 用途：moya `src/core/errors.ts` 的错误码→文案映射真源。文案原则：简体中文、无技术术语、
> 给出可行动下一步；同一 code 在家长/老师角色下文案不同时分行给出。

## 1. 复用通用码

| code | 场景 | 家长文案 | 老师文案 | 下一步动作 |
|---|---|---|---|---|
| 400 | 参数畸形 | 请求出错了，请返回重试 | 同左 | 自动回退上一页；重试一次仍失败则提示反馈 |
| 401 | 认证过期（真实 HTTP 401） | 登录已过期，正在重新登录… | 同左 | 请求层自动静默重登（session 刷新链）；重登失败→回登录页 |
| 403 | 资源级 ACL 拒绝 | 无权访问该内容 | 无权访问该内容 | 隐藏入口+页面显示"无权访问"空态；不提供重试（重试无意义） |
| 404 | 自身资源不存在 | 内容不存在或已删除 | 同左 | 回列表页并刷新 |
| 409 | 非法状态跳转 | 操作已完成，请刷新查看最新状态 | 同左 | 自动拉取最新数据覆盖本地 |
| 410 | 资源已删除 | 该内容已删除 | 同左 | 回列表页 |
| 422 | 参数校验失败 | 表单有误：{字段提示} | 同左 | 高亮对应字段 |
| 429 | 限流 | 操作太频繁，请稍后再试 | 同左 | 按钮冷却 30s |

## 3. 兜底文案（非 envelope code）

| 场景 | 文案 | 动作 |
|---|---|---|
| 网络不可达/超时 | 网络不给力，请检查网络后重试 | 重试按钮（保留当前页面状态） |
| 响应非 JSON/网关 5xx | 服务开小差了，请稍后再试 | 重试按钮；连续 3 次→反馈入口 |
| 未知 code（envelope code!=0 且不在上表） | 操作失败，请稍后重试（错误码 {code} 仅用于反馈） | 重试按钮 |
| 上传中断（wx.uploadFile fail） | 上传中断，已为您保留选择，点击继续上传 | 断点续传/重试（幂等键保证不重复） |

## 4. 实现注意（给 moya errors.ts）

- 401 走真实 HTTP 状态码分支（先判 HTTP 401 再判 envelope.code，契约头部注释）。
- 5404 按"空态引导"处理而非 toast（错误 UI 分流）。
- 5441/5423 等含 field 提示的，payload.field 映射到字段级文案（字段字典：learner_id→孩子、video→视频、photo→照片）。
- 全部文案不出现：openid、机构内部名、SQL、对象存储键（与错误码表使用规则 §3 一致）。
