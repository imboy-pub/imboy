# 老师操作卡（对应墨芽老师端实际页面流）

> 一页上手卡：moya 老师端已实现的流程（Step 15）；30 分钟培训用。
> 页面对应：待点评 Tab（队列）→ 工作台 → 发布确认 → 自动下一条。

## 0. 进入墨芽

1. 微信打开"墨芽习字"小程序 → 自动登录（无感）。
2. 若您同时是家长和老师：首次会弹出**身份选择**，选"老师 · 【班级名】"进入老师模式；以后可在"我的 → 身份切换"随时换。
3. 底部四个 Tab：**待点评 / 作业 / 班级 / 我的**。

## 1. 每日回评主流程（待点评 → 工作台 → 发布）

### 第 1 步：看待点评队列（待点评 Tab）

- 列表按提交时间排列，每张卡片：**学员名 · 作业名 · 第几次 · 提交时间 · AI 徽标**。
- AI 徽标含义（都不影响您处理）：
  - "AI 排队中 / AI 整理中"——还没整理好，您可以直接开始人工回评；
  - "AI 已整理"——草稿已备好，进工作台核对；
  - "AI 失败·人工 / 无 AI"——直接人工回评。
- 顶部筛选：班级下拉 + AI 状态横条（点"已整理"可只看有草稿的）。
- 家长撤回的提交会自动从队列消失，不会让您白做。
- 队列空 = "全部回评完成"✓。

### 第 2 步：点开一份 → 工作台

页面从上到下：
1. **学员提交**：练习视频（点播放）+ 作品照片 + 家长备注。
2. **AI 观察**（有草稿时显示）：AI 整理的几条要点——正向观察 ✓、主要问题 !、建议练习 ▸、口播提纲、证据时间点；⚠ 号表示"需人工特别核对"。
   - **核对方式**：点"**采用**"会把三条要点填进下方您的回评（可再改）；认为 AI 说得不对就点"**判断不准确**"（不影响您继续手写）。
3. **我的回评**（四要素 + 视频）：
   - 正向观察 / 重点问题 / 练习动作 / 补充说明——至少填一项，或只录视频；
   - **录制点评视频（≤60 秒）**：点按钮拍摄或选相册，超 60 秒会被拦下；上传失败点"上传失败 · 点击重试"（不会重复占空间）；
   - **需要重练**：勾选后家长端会看到"去重练"入口（孩子的下一次提交会新开一条记录，旧的都保留）。
4. **保存草稿**：随时保存，未通知家长。
5. **发布给家长**（红色按钮）→ 弹出**发布确认**：核对学员姓名、可见范围=该学员的监护人 → 点"确认发布"。

### 第 3 步：发布后

- 发布成功自动进入**下一条**（保持您刚才的筛选）；
- 全部处理完显示"全部回评完成"，回队列刷新即可。
- **发布失败**（如网络）：草稿内容已保留，原地重试即可，不会发两遍（重复点击也只有一条）。
- 特殊提示：若您是助教身份，会显示"已保存草稿，发布需任课老师操作"——请让任课老师完成发布。

## 2. 发布作业（首版最小流）

- 当前版本：作业发布在**后台/老师管理侧**配置（试点期由机构管理员操作）；老师端"作业"Tab 可看各作业的**待评进度**（待评 N 份、AI 已整理 N 份）。
- 发布时给家长的拍摄要求固定为：**约 1 分钟（≤60 秒）、练习纸平放、手部入镜**。

## 3. 班级 Tab

- 显示您的任教班级与角色（班主任/任课老师/助教）、每班待评数；点进班级即按该班过滤队列。

## 4. 我的 Tab

- **身份切换**：切到家长身份看自家孩子（再切回来）。
- **录制权限与隐私**：点评视频仅学员监护人可见；录制上限 60 秒。
- **清理缓存**：遇到显示异常时使用（会重新登录）。

## 5. 常见问题

| 问题 | 处理 |
|---|---|
| 视频播放不了 | 播放地址是短时授权的，回队列重进一次即重新获取；仍不行联系支持窗口 |
| 家长说提交失败 | 让家长在提交页点"重试提交"（系统保证不会重复提交）；连续失败记录时间报支持窗口 |
| 手滑发布了错的回评 | 试点期发布后不可撤回（发布确认页有提示）——发现错误立即联系机构处理 |
| AI 要点完全不沾边 | 点"判断不准确"，试点复盘会统计（用于改进或收窄 AI） |
