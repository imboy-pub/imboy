# 微信群现状基线采集表（试点前一周）

> 用途：试点指标以"相对微信群基线的改善"为准（计划 §12），本表是基线采集工具。
> **本表不含任何真实数据**——由机构老师在试点启动前的一周内如实填写；不填写则试点指标无对照，试点不得启动。
> 隐私约束：采集表只记时长/条数等计数与耗时，**不记录任何学员姓名、视频内容或聊天内容**。

## 0. 采集范围说明

- 对象：拟试点班级的现有微信群回课流程（一个班）。
- 周期：连续 7 天（建议覆盖一个完整作业发布周期）。
- 记录人：任课老师本人（耗时以老师主观计时+手机秒表/系统时间为准，允许±10% 误差，如实记录即可）。
- 工具：纸面或电子表格均可，用下方模板。

## 1. 四项基线指标采集方法

### 1.1 老师单份作业回评耗时（中位数来源）

**定义**：从"在微信群里找到某位学员的练字视频"到"完成并发出该学员的回评视频/文字"的端到端耗时（含观看练习视频、组织点评、录制、发送、以及中途被打断后重新找回的时间）。

**采集方法**：每处理一份，在模板表 2 记一行 start/end 与中断次数。一天多份逐份记录。

### 1.2 漏评率

**定义**：周期内已提交作业中学员中，截至周期结束未收到任何回评的学员占比。

**采集方法**：期末对照"作业要求提交名单"与"实际收到回评名单"，在表 3 填两列计数（名单本身不留档，只汇总数）。

### 1.3 平均回评等待

**定义**：学员提交时间到老师回评发出时间的中位间隔（小时）。

**采集方法**：微信消息时间戳自动可查；抽样记录表 2 的 submit_at 与 reply_at 列（每份一行，与 1.1 同表）。

### 1.4 家长查找成本

**定义**：家长为找到"自己孩子的最近一条回评/老师对自家孩子的历史建议"所需的操作成本。

**采集方法**：主观量表（无法客观计时）：周期末向家长发放一句话问卷——"上次想找回老师对你家孩子的一条回评时，你花了大约多长时间？（<1 分钟 / 1-5 分钟 / 5 分钟以上 / 没找到过 / 没找过）"。**问卷不收集姓名以外的任何信息，姓名仅用于计数去重后销毁**。回评等待与查找成本共用一次问卷，避免打扰。

## 4. 一周采样注意事项

1. 如实优先：漏评、超长等待也要记——基线的意义就是暴露现状，不美化。
2. 不改变现有流程：采集周即"正常的一周"，不因被观察而加速。
3. 问卷发放与回收由机构老师执行；家长可选不答（问卷首行注明"匿名统计，可跳过任何问题"）。
4. 汇总后的原始记录（表 2 等）按机构内部规定销毁；汇总表随试点包归档。
