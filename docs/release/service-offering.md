# IMBoy 私有化与定制服务说明

> 自托管即时通讯平台 · 数据主权 · 端到端加密
> 配套：[定价页 pricing.html](./pricing.html)

## 为什么选 IMBoy

- **数据主权**：完全自托管，E2EE（RSA-OAEP-256 + AES-256-GCM），服务端不解密。
- **成本优势**：同规模商业 IM（Slack/企微 200 人）约 $21,000/年，自托管硬件成本 < ¥3,000/年。
- **高并发省机器**：Erlang/OTP 内核，单机上万并发，国产化适配难度低于 Java 系。
- **内置钱包支付**：金融级钱包 + 付费频道 + 订阅，原生支撑付费社群/创作者经济。
- **交付高效**：改一处配置一键白标换牌，一条命令全栈部署 + Grafana 可观测。
