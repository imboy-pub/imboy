checkout HEAD（冲突仅来自旧 stash 应用，HEAD 即干净基线）；用户 stash

diff 导出/回放验证完好。**教训：本环境 git stash 不可靠（index 写入错
误），后续真红一律用 diff 导出 + checkout HEAD + git apply 的方式。**
