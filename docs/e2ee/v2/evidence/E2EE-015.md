## 修复前缺口

`UserRepoLocal.quitLogin` 仅清理内存公钥缓存（`E2EEService.clearCache`）与 JWT token。
以下秘密在 logout 后**全部残留**于 FlutterSecureStorage/磁盘：

1. RSA 身份私钥/公钥/kid/created_at（`e2ee_private_key` 等）；
2. RSA 历史私钥链（`e2ee_private_key_history_<kid>`，kid 集合未知，逐键枚举清不掉）；
3. 社交恢复分片与元数据（`e2ee_shard_*`）；
4. Olm account pickle / pickle key / session pickles（`olm_*`）；
5. Megolm inbound session pickles（`megolm_inbound_*`）与群 E2EE 旗标（`group_e2ee_mode_*`）；
6. SQLCipher DB key（`db_cipher_key_<uid>`）；
7. GroupSessionService/OlmSessionService/ComplianceKeyService 内存态；
8. 本地备份临时文件（temp 目录 `imboy_e2ee_backup_*.enc`）。

换号登录后新账号进程内可读到旧账号全部 E2EE 秘密。

## 实现

### 新增 `lib/service/e2ee/e2ee_secret_inventory.dart`
- `E2eeSecretInventory`：可测试 orchestrator，注入 `readAll/deleteKey/clearMemoryCaches/purgeArtifacts`。
- **前缀清单**（`secretKeyPrefixes`，覆盖 playbook 全部类别）：`e2ee_`（RSA/分片/DID/kid/backup 元数据）、`olm_`、`megolm_inbound_`、`group_e2ee_mode_`、`db_cipher_key_`、`mls_`（MLS 预留，尚无写入方）。前缀式清理天然覆盖 kid/uid/peer 参数化键（历史私钥链、session pickles）。
- **purgeAll 流程**：清内存缓存 → 清附属产物（Olm 状态、temp 备份文件）→ `readAll` 按前缀删除 → **再次 `readAll` 复核零残留**（平台层假成功也拦下）。逐项 continue-on-error 收集失败，任一失败抛 `E2eeSecretPurgeException`（fail-closed，不静默吞错）。
- `production()` 工厂接线：`StorageSecureService.readAll/delete` + `E2EEService.clearCache` + `ComplianceKeyService.clearCache` + `GroupSessionService.clearMemory`（新增）+ `OlmSessionService.clearAll` + temp 备份文件清理。

### `lib/store/repository/user_repo_local.dart`
- `quitLogin`：改调 `E2eeSecretInventory.production().purgeAll()`；失败置位 `Keys.e2eePurgePending`（shared_preferences，kill/restart 后保持）并返回 false（logout 不算成功）。
- `loginAfter`：顶部闸门——`e2eePurgePending` 置位时先补救 purge，仍失败则异常上抛，**拒绝建立新账号会话**。

### 支撑改动
- `storage_secure.dart`：新增 `readAll()` 包装。
- `group_session_service.dart`：新增 `clearMemory()`（outbound/inbound/staleGids/sendLocks）。
- `const.dart`：新增 `Keys.e2eePurgePending`。

## 设计说明
- **SQLCipher key 一并清除**：旧库 logout 后无 key 无法打开（验收要求）；同账号重登本地历史不可恢复，数据从服务端重新同步（zero-trust logout 语义）。
- **DID 一并清除**：logout 后设备对该账号的绑定作废，下次登录生成新 DID 重新注册；与 E2EE-016 的「备份不得覆盖**运行中**物理 DID」不冲突。
- token（`secure_token*`）不属 E2EE 清单，仍由 `SecureTokenStorageService.clear()` 负责（quitLogin 既有路径）。
