# 面聊记录 · V4 视觉基准与修订9交互细则 / Interaction specification

更新：2026-10-22。首版 BYOK 方向已获用户批准；修订9新增配置与处理交互待契约冻结和实施验收。V4 原型保留，不据本文宣称新增页面已实现。配合 DESIGN.md、BACKEND-API.md、PLAN.md 使用。

## 1. 统一页面骨架 / Layout contract

导航区、可滚动正文、底部操作区依次参与布局，不用浮层覆盖内容。产品横向内边距16pt；组内间距12/16pt、组间24pt；触达区≥44pt，主要操作≥48pt；所有正文区域允许换行与垂直滚动。长姓名、角色与末尾操作不能挤压正文：授权名单的操作放独立下一行。

正文16pt、辅助14pt、标题20/22pt、计时40pt（等宽数字）。实施时映射 AppColors/AppSpacing/FontSizeType；原型CSS不是另一个Flutter主题。灰色文字不得靠过低透明度弱化。只读不能只用颜色区别，显示角色文字。

导航返回优先返回上一页，而不是统一回列表。退出录音页保留全局录音条，不自动停止。系统麦克风权限/设置/系统分享面板使用平台标准组件，不要求复制网页外观。顶部场景、右侧角色/能力/异常按钮仅为评审工具，正式产品不显示。

## 2. 页面与关键操作 / Screen contracts

| 页面 | 内容与交互 | 结果及失败 |
|---|---|---|
| 个人入口 | 我→个人工具→面聊记录 | 个人上下文进入列表，不默认企业 |
| 企业入口 | 工作台→协作工具→面聊记录 | 带当前企业；不带未知工作区、不暗示全员可读 |
| 列表 | 全部/我创建/共享给我；搜索；录音条；创建入口 | 空结果保留筛选和搜索，不把“无结果”误报“从未创建”；上传状态来自服务端，只有本机的草稿标记本机 |
| 准备 | 标题选填，保存到，处理方式；企业协作信息折叠选填 | 先核权限/企业外发策略，再显示MiniMax转写、智谱摘要及数据用途；缺本机Key可去AI服务，或明确选择仅录音；开始前确认已告知及相应处理同意 |
| AI 服务 | 语音转文字（MiniMax）/文本整理（智谱）两行分组列表 | 当前账号本设备的未配置/已配置/需更新状态；进入详情保存、主动验证、替换、删除，不显示其他账号Key |
| 服务配置 | 固定供应商/模型、掩码Key、仅本设备和费用说明 | 保存配置不自动发请求；验证连接需明确提示可能计费；换设备重新填写，不提供云同步Key |
| 保存位置 | 选择个人或有权企业 | 变更前说明保留标题、清空不适用参与者；确认后更改本次草稿，不迁移已有记录 |
| 录音 | 计时、录音状态、本机分段状态、重点列表 | 暂停不计时；中断手动继续；空间不足停止写入并明确保留实际落盘部分；结束确认后保存 |
| 处理 | 本机保存/上传/等待本设备处理/转写块数/摘要各阶段 | 上传与AI请求分别恢复；已完成块不因重启重做；每次外发和提交结果前重验权限/企业策略；未知供应商结果不自动重发，进度只来自真实已完成块 |
| 详情 | 可见范围概述、角色、摘要/原文、播放器、共享补充笔记 | 仅录音/无语音不渲染虚构正文；摘要过时明确标记；读者只读，编辑者可校对，创建者管理分享 |
| 原文校对 | 片段时间点、回听、可编辑文字、保存 | 原音频不变；保存使摘要过时；版本冲突保留本次输入供核对，不能静默覆盖 |
| 发言人 | 请求块内匿名标签/人工标记来源、试听、显示姓名 | 不同块S1不可默认合并；允许回听后人工改名/合并并处理冲突；只作用于本记录，不建立声纹或当本人认证 |
| 分享管理 | 创建者＋实际授权名单；角色、导出能力、编辑/撤销 | 没有任何授权时不提供“发送卡片”主操作；授权成功与发送成功分开反馈 |
| 编辑权限 | 企业同事/个人联系人；查看或编辑；导出权限 | 明确编辑者不能管理ACL或删除；策略禁导出时禁用并说明；保存后回名单 |
| 更多管理 | 导出、企业移交、删除，按角色/能力出现 | 只读/编辑者不显示责任移交和删除；业务接口仍需独立鉴权 |
| 导出 | txt/md、是否可导出、生成与到期状态 | 主动确认独立副本无法收回；真实下载前再验权限；原型不生成实际文件 |
| 责任移交 | 新责任人、原责任人是否保留查看 | 默认不保留，二次确认；成功后按所选保留查看或通用失效页；归属不变 |
| 删除状态 | 已逻辑删除＋正在清理/hold/留存/失败/完成 | 不再展示正文；清理失败可重试；受治理保护不等同清理异常 |

## 3. 角色与能力 / Roles and capabilities

| 操作 | owner | editor | viewer |
|---|---|---|---|
| 查看/回听 | 是 | 是 | 是 |
| 修改原文/发言人/共享笔记 | 是 | 是 | 否 |
| 管理授权/撤销 | 是 | 否 | 否 |
| 删除 | 是（受治理限制） | 否 | 否 |
| 移交企业记录责任 | 是（目标仍须合法） | 否 | 否 |
| 导出文字 | 当前策略允许 | grant.allow_export 且策略允许 | grant.allow_export 且策略允许 |

右侧“允许导出”是当前查看者有效能力的评审开关（包含grant与策略结果），不是viewer默认都能导出。切换评审角色默认撤去非owner导出，需显式演示授权允许状态。新建录音后创建者角色重新为owner。完整接收者名单仅owner查看，其他人看自己的权限和可见范围概述。

## 4. 状态文案与反馈 / State language

- 录音中：“正在录音 · 本机分段保存”；暂停：“已暂停，不计入录音时长”。
- 断网：“网络已断开，继续保存在本机。联网后重新校验权限并上传。”
- 无语音：“未检测到可转写语音。录音已保留。”不显示“转写失败”。
- 转写失败：“转写失败，录音仍可回听”；仅有当前处理权限且本设备配置/策略允许的编辑者可继续，查看者联系创建者。
- 等待本设备：“录音已保存。打开此设备并联网后继续整理。”不承诺退出App后持续执行。
- Key未配置：“在本设备配置 MiniMax 后可转写”；仅缺智谱时保留原文，提示配置后可生成摘要。
- 外发被禁：“当前企业不允许使用此AI服务”；不给出转存个人空间绕过策略的操作。
- 摘要：“AI 整理草稿 · 使用前请核对”；修改原文后：“原文或署名已更新，摘要可能过时”。
- 共享笔记明确“随记录共享”，不叫“我的私密笔记”。
- 保存权限：“权限已保存”；发送卡片只有真正发送成功后才显示“已发送”。原型对应结果均注明示例。
- 撤权：“将无法继续访问原记录。已导出或保存的副本无法收回。”
- 无权限/不存在统一：“暂时无法查看”；不泄露记录标题与人员，也不凭错误推断用户已离职。
- 删除先显示“记录已删除”，下方独立展示附件清理状态，不将排队成功冒充字节已删除。

本轮脚本验证仅为DOM模拟：两种归属×三角色×16页共96状态；274个动态事件语法检查；授权保存/撤销、跨空间返回原录音、16种恢复情景。不是截图对照、真实音频、真实权限或API验收。

## 6. 修订9 AI 服务与恢复细则 / BYOK configuration and recovery

配置沿用统一分组列表、左右16pt和现有Token，不增加独立品牌色或九宫格。入口为“设置 → AI 服务”，准备/处理页缺配置提示跳同一详情，返回时保留原草稿与原归属。列表只显示供应商、用途与配置状态；Key详情默认掩码，不预填其他账号的值，不自动复制到剪贴板。若提供短暂显示Key需用户主动操作，返回后台即恢复遮蔽。

保存页固定说明：“Key仅加密保存在当前账号的本设备，不上传IMBoy服务器，不随备份或换机迁移。音频/原文会发送至所选服务商并可能计费。”按需分别授权语音转写与文本整理，不能用“Key不上传”暗示内容不外发。智谱页面说明采用通用API；“拥有年度Max”不显示为免费或已包含会议整理额度，Coding Plan与通用调用的区别见DESIGN.md §12。

| 状态 | 提示与操作 | 不得发生 |
|---|---|---|
| 保存配置 | “已保存在本设备”；可随后主动验证 | 保存后自动上传真实录音、自动验证扣费 |
| 验证连接 | 展示使用的非敏感样本与可能费用，用户点“验证”才请求 | 隐式使用当前企业录音或其他记录正文 |
| 401 | “Key无效或已失效，请更新”；保留录音与已完成结果 | 自动反复重试或换用其他账号Key |
| 402/供应商余额不足 | “服务商余额不足，充值后继续”；不代充值 | 自动切换收费供应商、自动购买额度 |
| 429 | “请求较多，稍后继续”；可暂停，有界退避 | 无上限重试、将等待显示成完成 |
| 超时/响应丢失 | “结果未确认，服务商可能已处理并计费”；保留检查点，说明再次请求可能重复计费 | 把未知当未处理、自动无限重发 |
| 删除Key | 二次确认后删除本账号本设备配置并停止新的该服务请求；保留已保存记录 | 删除云端记录、影响其他账号、承诺撤销已发出的供应商请求 |
| 账号/空间/策略变化 | 暂停，回到原记录重验；权限失效不再外发/发布迟到结果 | 转个人归属、跨账号借Key或沿用旧策略同意 |

录音附件上传和供应商请求用不同状态展示；转写失败不再上传已确认附件，摘要失败不丢原文。已成功块显示真实完成数量；部分结果允许回听与校对，不称整条记录处理完成。音频块保留全局时间定位，边界文字去重不得丢失原句。分块说话人未人工关联时明确“第N段 · 说话人1”等作用域，不伪装成全程同一人；原文校对和说话人更正使旧摘要标记过时。

设备验证必须覆盖Key掩码、切账号隔离、退出/删除清除、备份与换机不带Key、断网与后台/被结束后恢复、401/402/429及未知请求状态、大字/键盘/安全区。供应商真实调用和企业外发策略要与服务端结果/版本/撤权栅栏联调；本节只规定交互，不作为这些行为已实现或已通过的证据。
