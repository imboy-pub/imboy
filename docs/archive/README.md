## 什么时候把文档放进来

- 一次性工作完成：评审、审计、修复计划、检查单 → 工作关闭时移入
- 文档被取代：新版发布，旧版移入（不删除）
- 内容过期：描述的行为与当前代码明显不符，且无更新价值

## 什么时候**不要**放进来

- 进行中的工作文档 → 放 [../planning/](../planning/)
- 仍被引用的契约/参考 → 放 [../reference/](../reference/)
- 仍可执行的操作指南 → 放 [../guides/](../guides/)

## 纪律

- 移入时用 `git mv`，保留历史。
- 移入后更新所有引用点（`grep -rl <文件名>` 排查）。
- 本目录内容**永不删除**；如需找回，直接 `git mv` 回去即可。
