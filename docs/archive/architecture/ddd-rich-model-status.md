# DDD 架构边界参考

本页保留既有文档入口，架构规则以[DDD 迁移决策](../../adr/0006-ddd-migration-endpoint.md)和[功能切片规则](../../architecture/feature-slice-rules.md)为准。

领域状态不变量、无状态编排、数据访问和表现层规则按各自合同维护。迁移决策规定按实际改动触发迁移，不要求为了目录形式批量重写未受影响的模块；已明确的例外也应按决策维护。

客户端既有架构取舍继续保留：Repository ports 可位于 `infrastructure/` 并使用 `sqflite Transaction` 表达现有事务边界；`message_models` 可作为 re-export barrel 保持既有调用入口。不要仅为目录形式或移除转导出而重写事务调用链；需要改变这些边界时应另行评审。

历史实施评估、阶段任务完成数量、编译与测试成绩、真机回归待办均保存在仓外，不在此页作为当前代码或交付通过的证明。验证结果必须绑定实际候选与运行证据。

历史未签收的真机回归门不会因本次文档提炼而关闭。
