- 不 reset/clean/stash，不覆盖共享改动；未经人工确认不 commit，不 push，不执行外部或生产动作。

- Status：`ready`
- Owner：Coordinator
- Dependencies：无
- Scope：只读盘点 `imboy`、`imboyapp`、`imboyadmin`；在 `$IMBOY_EVIDENCE_ROOT` 创建证据，不写仓库。
- Actions：
  1. 执行 §4.1 路径探测，记录解析后的聚合目录、证据目录、三仓 HEAD、branch、dirty paths 和目标路径现有 owner。
  2. 自动扫描并断言 `00000090..93` 未占用；确认 `imboy-sdk-js` 是否仍缺失。
  3. 扫描仓库中真实存在的 EUnit 模块，把任务卡计划名映射为实际模块名；缺失项记录为 `missing`，不得静默跳过或凭名字新建空测试。
  4. 运行当前 Agent/MCP/Bot/Webhook/Task 聚焦基线，记录每模块 passed/failed/skipped。
  5. 记录当前构建期 feature 清单与三端生成物 hash。
  6. 创建任务 owner 表；有交叉脏文件的任务标记 `blocked_owner`。
- Verify：

```bash
mkdir -p "$IMBOY_EVIDENCE_ROOT/G0-01"
git -C "$IMBOY_WORKSPACE_ROOT/imboy" rev-parse HEAD && git -C "$IMBOY_WORKSPACE_ROOT/imboy" status --short --branch
git -C "$IMBOY_WORKSPACE_ROOT/imboyapp" rev-parse HEAD && git -C "$IMBOY_WORKSPACE_ROOT/imboyapp" status --short --branch
git -C "$IMBOY_WORKSPACE_ROOT/imboyadmin" rev-parse HEAD && git -C "$IMBOY_WORKSPACE_ROOT/imboyadmin" status --short --branch

occupied="$(find "$IMBOY_WORKSPACE_ROOT/imboy/priv/migrations" -maxdepth 1 -type f -name '0000009[0-3]_*.sql' -print)"
printf '%s\n' "$occupied" > "$IMBOY_EVIDENCE_ROOT/G0-01/migration-reservations.txt"
test -z "$occupied"

cd "$IMBOY_WORKSPACE_ROOT/imboy"
rg --no-filename --glob '*_tests.erl' '^-module\(' test \
  | sed -E 's/^-module\(([^)]+)\)\.$/\1/' \
  | sort -u > "$IMBOY_EVIDENCE_ROOT/G0-01/test-modules-discovered.txt"
rg --no-filename -o 'make eunit-local t=[A-Za-z0-9_]+' docs/planning/tasks/*.md \
  | sed 's/.*t=//' \
  | sort -u > "$IMBOY_EVIDENCE_ROOT/G0-01/test-modules-planned.txt"
{
  printf 'planned\tactual\tstatus\n'
  while IFS= read -r module; do
    if rg -qx "$module" "$IMBOY_EVIDENCE_ROOT/G0-01/test-modules-discovered.txt"; then
      printf '%s\t%s\tfound\n' "$module" "$module"
    else
      printf '%s\t\tmissing\n' "$module"
    fi
  done < "$IMBOY_EVIDENCE_ROOT/G0-01/test-modules-planned.txt"
} > "$IMBOY_EVIDENCE_ROOT/G0-01/test-module-map.tsv"
# missing 只能由 Coordinator 根据仓库中的明确重命名证据改为 mapped；不得猜测。
test -s "$IMBOY_EVIDENCE_ROOT/G0-01/test-module-map.tsv"
```
