# 群与频道附件下载

`GET /api/v1/attachment/view_url?object_key=...` 的登录认证与返回结构不变。
群和频道的对象存储附件返回 IMBoy `/api/v1/attachment/content?ticket=...` 地址，
不再向客户端返回 S3 下载直链。公开资源、个人附件及旧 go-fastdfs 读取保持原合同。

## 内容读取

- `GET` 和 `HEAD /api/v1/attachment/content?ticket=...` 使用专用下载凭证；
  无凭证、畸形、错误签名、过期、登录令牌误用或当前权限不足返回 `403`。
- 凭证绑定用户与对象路径，有效期 600 秒，签名密钥从现有 JWT 密钥按用途派生。
  下载凭证不能作为登录令牌；持有者只能请求该对象，并且每次读取仍检查当前成员权限。
- 群历史世代、企业和工作区成员、频道角色或订阅权限继续采用原授权逻辑。
  软删除附件拒绝签发和读取。请求开始及存储响应头到达时均复核权限。
- 支持单个 `Range: bytes=start-end`、开放结尾与尾部范围；多段或畸形范围返回 `416`。
  有效范围返回 `206` 和存储提供的 `Content-Range`；HEAD 保留真实文件长度。
- 使用 OTP HTTP 客户端逐块拉取并写出，禁止存储重定向；不将整份文件缓存到进程内。
  响应设置 `Cache-Control: private, no-store`、`nosniff` 和沙箱策略。
- `base_url` 必须配置为客户端能访问的 IMBoy HTTP(S) 地址；JWT 密钥必须存在。
  配置缺失时拒绝签发，不回退到对象存储直链。

## 验证与兼容边界

真实隔离 PostgreSQL + Garage 检查包含上传、整份读取、HEAD、Range、坏凭证、
暂停后同一链接拒绝、恢复后读取、删除后同一链接拒绝，以及原清理和并发恢复检查。
测试入口为 `enterprise_asset_garage_pg_checks:run/0`，由隔离存储/数据库运行器调用。

已交付到客户端的字节不能撤回；开始发送后的流不会逐块查询数据库。
变更前已签发的 S3 链接仍可能在原有效期内读取，应在发布验收中单独处理过渡窗口。
旧 go-fastdfs 直链仍需独立完成失权验证与兼容治理；本检查不证明这些历史链接可即时撤销。
真机文件预览、iOS、完整冻结候选与生产环境仍需各自验收。
