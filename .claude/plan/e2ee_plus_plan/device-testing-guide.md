## 🧪 测试流程

### 测试场景 1：首次生成密钥

**目标**: 验证用户可以生成新的 E2EE 密钥对

**步骤**:

1. **登录应用**
   - 使用测试账号登录
   - 确保登录成功

2. **进入设置**
   - 点击底部导航栏"我的"
   - 点击"设置"

3. **打开 E2EE 密钥管理**
   - 找到"E2EE 密钥管理"菜单项
   - 点击进入密钥恢复页面

4. **生成新密钥**
   - 如果页面显示"无密钥"状态，点击"生成新密钥"按钮
   - 等待密钥生成完成（约 3-5 秒）
   - 验证成功对话框显示

**预期结果**:
- ✅ 密钥生成成功对话框弹出
- ✅ 显示设备 ID（格式：`xxxxxxxx-xxxxxxxx-xxxxxxxx`）
- ✅ 显示密钥 ID（格式：`kid_xxxxxxxx`）
- ✅ 显示密钥算法（RSA-2048）
- ✅ 提示用户立即备份
- ✅ 点击"去备份"按钮跳转到备份导出页面

**截图检查点**:
- [ ] 密钥生成成功对话框
- [ ] 设备 ID 格式正确
- [ ] 密钥 ID 格式正确

---

### 测试场景 2：导出密钥备份

**目标**: 验证用户可以导出加密的密钥备份

**步骤**:

1. **进入备份导出页面**
   - 从密钥恢复页面点击"去备份"
   - 或直接导航到备份导出页面

2. **输入备份密码**
   - 输入强密码（至少 8 位，包含大小写字母、数字、特殊字符）
   - 观察密码强度指示器
     - 弱密码：红色，强度 < 30%
     - 中等：橙色，强度 30-70%
     - 强：绿色，强度 > 70%

3. **测试密码验证**
   - 尝试输入弱密码（如 "123456"）
     - 预期：显示错误提示
   - 输入强密码（如 "TestPass123!"）
     - 预期：密码强度显示绿色

4. **添加备注（可选）**
   - 在"备注"字段输入描述（如"主手机备份"）

5. **导出备份**
   - 点击"导出备份"按钮
   - 等待加密和文件生成（约 2-3 秒）
   - 选择保存位置（系统分享面板）

6. **保存备份文件**
   - 保存到设备本地或云盘
   - 记住文件名（格式：`imboy_e2ee_backup_YYYY-MM-DDTHH-MM-SS.enc`）

**预期结果**:
- ✅ 密码强度指示器正常工作
- ✅ 弱密码被拒绝
- ✅ 强密码被接受
- ✅ 备份文件成功生成
- ✅ 文件名格式正确
- ✅ 分享面板正常弹出

**截图检查点**:
- [ ] 密码强度指示器（弱/中/强）
- [ ] 弱密码错误提示
- [ ] 备份成功提示

### 测试场景 5：从备份恢复密钥

**目标**: 验证用户可以从备份文件恢复密钥

**步骤**:

1. **确保当前无密钥**
   - 如果有密钥，先删除

2. **进入备份导入页面**
   - 从密钥恢复页面点击"导入备份"

3. **选择备份文件**
   - 点击"选择文件"按钮
   - 浏览到之前保存的 `.enc` 文件
   - 选中文件

4. **输入备份密码**
   - 输入导出时设置的密码

5. **导入备份**
   - 点击"导入密钥"按钮
   - 等待解密和恢复（约 2-3 秒）

**预期结果**:
- ✅ 文件选择器正常打开
- ✅ 选中的文件信息显示（文件名、大小）
- ✅ 导入成功对话框弹出
- ✅ 显示恢复的设备 ID 和密钥 ID
- ✅ 提示旧消息可能无法访问

**截图检查点**:
- [ ] 文件选择界面
- [ ] 选中的文件信息
- [ ] 导入成功对话框

### 测试场景 7：备份文件完整性验证

**目标**: 验证备份文件格式正确

**步骤**:

1. **导出一份备份**

2. **找到备份文件**
   - iOS: 模拟器中通过 Files 应用
   - Android: 通过文件管理器或 ADB

3. **验证文件属性**
   - 文件扩展名: `.enc`
   - 文件大小: 约 2-3 KB（取决于备注长度）

4. **（可选）使用十六进制编辑器查看文件头**
   - 前 8 字节: `IMBOYBKP` (Magic Number)
   - 第 9-10 字节: 版本号 `0x0001`
   - 第 11-12 字节: 算法 ID `0x0001`
   - 第 13-16 字节: 迭代次数 `0x0004BC20` (310,000)

**预期结果**:
- ✅ 文件格式符合规范
- ✅ 文件头包含正确的 Magic Number

## 🐛 已知问题

### 问题 1: 文件选择器限制
- **描述**: 某些 Android 设备的文件选择器可能不显示 `.enc` 文件
- **解决方案**: 在文件选择器中启用"显示所有文件"

### 问题 2: 大文件备注
- **描述**: 用户备注过长可能导致备份文件过大
- **解决方案**: 限制备注长度为 500 字符
